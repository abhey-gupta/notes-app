# Notespace — Day 0 scope

Handwritten notes for iPad. Headline: ultra-fast, minimal, beautiful.

## Perf budgets
- Cold launch → library: < 400 ms
- Open notebook → first page inked: < 150 ms
- Ink latency: hardware floor (predicted touches), 120 Hz
- Scroll/zoom: 120 Hz, no dropped frames on 100+ page notebooks
- No spinners

## In
- Library: recents w/ live previews, notebook covers, 1-level folders, title search
- Canvas: pen (fountain/ballpoint/brush), highlighter, eraser (stroke + partial), lasso (move/resize/recolor), 3 quick colors, undo/redo
- Pencil: palm rejection, double-tap/squeeze → eraser, pressure/tilt
- Pages: vertical continuous scroll, pinch zoom, templates (blank/lined/dotted/grid/Cornell), overview w/ reorder/add/delete
- Dark mode (night paper), focus mode (chrome collapses)
- Local-first autosave, export PDF / share sheet

## Out (post Day 0)
PDF import/annotation, iCloud sync, handwriting search/OCR, audio, text boxes, shape snap, AI, collab, infinite canvas, stickers.
